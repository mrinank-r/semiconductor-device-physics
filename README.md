# Semiconductor device physics

A collection of numerical simulations exploring semiconductor device physics.
The project currently focuses on one-dimensional models of semiconductor junctions based on their underlying physical equations.

## Current progress

### Homojunctions
1D equilibrium models of silicon p-n junctions, including:
- Poisson equation solver
- Abrupt p-n junction
- Linearly graded p-n junction

## Future work

- Applied bias
- Drift-diffusion transport
- Heterojunctions
